# v0.1.0-alpha.1
- First alpha release.
- Three-state indicator: green (clear), yellow (anomaly, not enough evidence), red (high-confidence detection).
- Detectors: speed, physics, TPS, time scale, clock, noclip, clicks and suspicious mods, each with independent state.
- A suspicious mod being loaded only turns the light yellow, and the scan runs once per level.
- Settings button in the pause menu, with a configurable dot position, size and opacity.
- Run report saved when a level is completed.
- Debug logging option for troubleshooting.
